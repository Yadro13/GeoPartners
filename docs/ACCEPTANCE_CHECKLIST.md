# Приймальний чек-лист GeoPartners

Дата актуалізації: 6 серпня 2026 року.

## Автентифікація і доступ

- [x] Реєстрація за email і паролем.
- [x] Підтвердження email.
- [x] Google OAuth для користувачів.
- [x] Схвалення або відхилення нової реєстрації адміністратором.
- [x] Коментар адміністратора у повідомленні про рішення.
- [x] Email і Telegram сповіщення адміністратору.
- [x] Ролі `user` та `admin`, перевірка прав на сервері.
- [x] Рівні користувача `read`/`edit`, нові користувачі за замовчуванням `read`.
- [x] Адміністратор змінює рівень у реєстрі; API блокує запис для `read`.
- [x] Витрати бачить і змінює лише адміністратор; `read`/`edit` не отримують суми через API, UI, аудит або експорти, а редагування дат зберігає приховані суми.
- [x] Зміна і відновлення пароля.
- [x] Адміністратор входить лише за email/паролем.

## Ділянки і документи

- [x] Перегляд і пошук для `read`; створення та редагування для `edit` і адміністратора.
- [x] Впорядкований довідник статусів: CRUD і зміна порядку адміністратором.
- [x] Окреме вікно етапів: незалежні прапорці, редаговані дата й час та витрати для кожного пройденого етапу.
- [x] Адміністратор і користувач `edit` змінюють проходження та дати етапів; `read` переглядає їх без редагування, витрати адмініструє лише адміністратор.
- [x] Перейменування етапу оновлює пов'язані ділянки, видалення прибирає етап та його реквізити.
- [x] Видалення ділянок адміністратором.
- [x] Редактор контуру та перевірка геометрії.
- [x] Масовий імпорт папки, окремих GeoJSON/PDF і ZIP адміністратором без користувацького ліміту 60 файлів.
- [x] GeoJSON імпортується без PDF; за наявності PDF зберігаються оригінал, дата актуальності, усі власники й повний орендар.
- [x] M1 розгорнуто у Railway staging 5 серпня 2026 року; міграцію БД і health PostgreSQL, сповіщень та Bucket підтверджено.
- [x] Попередній перегляд, вибір об'єктів і блокуючі пояснення.
- [x] Обмеження пакета імпорту та перевірка фактичної PDF-сигнатури.
- [x] Захищена розпаковка ZIP з перевіркою шляхів, кількості та розміру файлів.
- [x] Журнал змін, порівняння і відновлення версій.
- [x] Погоджено правила накладань: вони інформаційні, не блокують операції, координати GeoJSON зберігаються без змін.
- [x] CRUD та аудит перевірено через реальні API/PostgreSQL у Railway staging `sandbox` 24 липня 2026 року; тимчасові дані очищено.
- [x] Автоматизований Railway staging E2E перевірив реєстрацію, email, схвалення, права, області даних, аудит, відновлення та призупинення 24 липня 2026 року; cleanup підтверджено.
